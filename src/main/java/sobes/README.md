### BinaryTreeCodec
Сериализация и десериализация бинарного дерева
Реализация алгоритма для сериализации бинарного дерева в строку и восстановления дерева из строки.

### DiningPhilosophers
Проблема обедающих философов
Решение классической задачи синхронизации, где несколько философов сидят за круглым столом и пытаются одновременно есть, используя вилки между ними.

### LRUCache
Кэш с вытеснением по давности использования (LRU)
Реализация кэша, который вытесняет наименее недавно использованные элементы при достижении максимального размера.

### LinkedLogList
Односвязный список с функцией реверса
Реализация односвязного списка с возможностью добавления элементов и создания реверсированной копии списка.

### ListNode
Узел односвязного списка
Класс, представляющий узел односвязного списка с целочисленным значением и ссылкой на следующий узел.

### MapSum
Хэш-таблица с префиксными суммами
Реализация структуры данных, которая хранит пары ключ-значение и позволяет быстро вычислять сумму значений по заданному префиксу ключа.

### MapSumTrie
Префиксное дерево с суммами значений
Реализация структуры данных на основе префиксного дерева (Trie) для хранения пар ключ-значение с возможностью быстрого вычисления суммы значений по префиксу.

### MedianFinder
Поиск медианы в потоке данных
Реализация структуры данных для нахождения медианы в потоке целых чисел с использованием двух куч.

### MyBlockingQueue
Блокирующая очередь
Реализация блокирующей очереди с фиксированной емкостью, которая блокирует потоки при попытке добавления в полную очередь или извлечения из пустой.

### MyQueue
Очередь на основе двух стеков
Реализация очереди (FIFO) с использованием только двух стеков, поддерживающая все стандартные операции очереди.

### MyStack
Стек на основе очереди
Реализация стека (LIFO) с использованием только одной очереди, поддерживающая все стандартные операции стека.

### PrefixTree
Префиксное дерево (Trie)
Реализация префиксного дерева для эффективного хранения и поиска строк, с возможностью проверки наличия слова и префикса.

### RangeSumQuery
Сумма элементов в диапазоне
Реализация структуры данных для быстрого вычисления суммы элементов массива в заданном диапазоне индексов.

### RateLimiter
Ограничитель частоты запросов
Реализация ограничителя частоты запросов, который позволяет контролировать количество запросов в заданный временной интервал.

### ThreadSafeSingleton
Потокобезопасный синглтон
Реализация паттерна Singleton с двойной проверкой блокировки для обеспечения потокобезопасности.

### Solution
Набор алгоритмических решений
Коллекция решений для различных алгоритмических задач, включая задачи на строки, массивы, деревья, графы и динамическое программирование.

#### Методы класса Solution:

##### lengthOfLongestSubstring
Поиск длины самой длинной подстроки без повторяющихся символов
Использует скользящее окно для нахождения максимальной длины подстроки, в которой все символы уникальны.

##### trap
Сбор дождевой воды
Вычисляет, сколько воды может быть собрано после дождя, учитывая карту высот. Использует двухуказательный подход для эффективного решения.

##### merge
Объединение интервалов
Объединяет пересекающиеся интервалы в непересекающиеся. Сначала сортирует интервалы по началу, затем объединяет пересекающиеся.

##### hasCycle
Проверка наличия цикла в связном списке
Использует алгоритм Флойда (медленный и быстрый указатели) для определения наличия цикла в односвязном списке.

##### mergeTwoLists
Объединение двух отсортированных списков
Объединяет два отсортированных связных списка в один отсортированный список, сохраняя порядок элементов.

##### isValidBST
Проверка валидности бинарного дерева поиска
Проверяет, является ли данное бинарное дерево действительным бинарным деревом поиска, используя рекурсивный подход с ограничениями.

##### isSameTree
Проверка идентичности двух бинарных деревьев
Сравнивает два бинарных дерева на структурную идентичность и равенство значений узлов. Поддерживает как рекурсивную, так и итеративную реализацию.

##### canFinish
Планирование курсов
Определяет, возможно ли пройти все курсы, учитывая их зависимости (предварительные условия). Использует топологическую сортировку.

##### climbStairs
Подъем по лестнице
Вычисляет количество различных способов подняться на n ступенек, когда можно подниматься на 1 или 2 ступеньки за раз. Использует динамическое программирование.

##### coinChange
Сдача минимальным количеством монет
Находит минимальное количество монет, необходимое для формирования заданной суммы. Использует динамическое программирование.

##### lengthOfLIS
Поиск самой длинной возрастающей подпоследовательности
Находит длину самой длинной возрастающей подпоследовательности в массиве. Использует бинарный поиск для оптимизации.

##### findKthLargest
Поиск K-го по величине элемента в массиве
Находит K-й по величине элемент в массиве, используя мин-кучу для эффективного решения.

##### isWildcardMatch
Сопоставление строки с маской
Проверяет, соответствует ли строка заданному шаблону с подстановочными символами ('*' и '?'). Использует динамическое программирование.

##### compressRLE
Сжатие строки методом RLE
Выполняет сжатие строки с использованием алгоритма RLE (Run-Length Encoding), заменяя последовательности одинаковых символов на символ и количество повторений.

##### findCheapestPrice
Поиск самого дешевого пути с ограничением пересадок
Находит самый дешевый маршрут между городами с ограничением на количество пересадок. Использует модифицированный алгоритм Дейкстры.
