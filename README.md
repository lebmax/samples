### ArrayIntersection
Даны два отсортированных списка с интервалами присутствия
пользователей в онлайне в течение дня. Начало интервала строго меньше конца.
Нужно вычислить интервалы, когда оба пользователя были в онлайне.

### CountArrPairs
Дан массив интов и число K, K >= 0.
Нужно найти количество пар(уникальных или не уникальных,
с точки зрения их значения) элементов, разница которых >= K

### FilterSortedListByAnother
Даны две отсортированных по неубыванию последовательности целых чисел.
Необходимо вернуть все элементы из первой последовательности, которых нет во второй.

### FindKClosestElements
Дан отсортированный массив целых чисел a, индекс элемента index и целое число k.
Необходимо вернуть в любом порядке k чисел из массива,
которые являются ближайшими по значению к элементу a[index]

### FuzzySearch
Реализовать функцию приблизительного совпадения строк

### LowestCommonAncestor
Найти ближайшего общего предка двух узлов дерева
Самый низкий общий предок определяется между двумя узлами p и q как самый низкий узел в T,
который имеет как p, так и q в качестве потомков (где мы разрешаем узлу быть потомком самого себя).

### MaxDistanceToClosest
Места в кинотеатре расположены в один ряд. Только что пришедший зритель выбирает место,
чтобы сидеть максимально далеко от остальных зрителей в ряду.
То есть расстояние от того места, куда сядет зритель до ближайшего к нему зрителя
должно быть максимально.

### MaxGuests
Даны даты заезда и отъезда каждого гостя.
Для каждого гостя дата заезда строго раньше даты отъезда (то есть каждый гость останавливается хотя бы на одну ночь)
Необходимо написать функцию, которая считает максимальное число посетителей, которые одновременно проживали в гостинице.

### MaxMonotonous
Дан массив чисел a_1, a_2, ..., a_n.
Необходимо найти монотонный подотрезок (то есть строго убывающий или строго возрастающий)
максимальной длины и вернуть пару индексов его начала и конца.

### MaxSubArrOnes
Дан непустой массив из нулей и единиц. Нужно определить, 
какой максимальный по длине подынтервал единиц можно получить,
удалив (пропустив) ровно один элемент массива

### MaxSubstr
Задана строка S из малых латинских букв,
требуется узнать длину наибольшей подстроки состоящей
не более чем из двух различных символов.

### MinDistanceArrElement
Дана строка, состоящая из букв 'X', 'Y' и 'O'.
Необходимо найти кратчайшее расстояние между буквами 'X' и 'Y',
либо вывести 0, если 'X' либо 'Y' отсутствуют.

### MinDistanceTwoArrEl
Даны два массива a и b. Нужно найти минимум abs(a[i]-b[j]):

### Multiply
Длинное умножение на разряд
Дана строка из десятичных цифр (длинное число, младшие разряды расположены по младшему индексу).

### NormalizeWhitespace
Заменить последовательности пробелов в строке на одиночные пробелы. O(n) по времени, O(1) по памяти.

### NumSubstrWithoutRepetitions
Дана строка символов. Найти количество пар индексов i и j, между которыми, включительно, нет повторяющихся символов.

### OneEditApart
Нужно реализовать функцию, проверяющую, можно ли одну строку получить из другой не более,
чем за одно исправление (удаление, добавление, изменение символа)

### PermutationInString
Дан текст T и строка S. Требуется найти подстроку S' в T такую, что она совпадает с S с точностью до перестановки букв.

### ScalarProductCompactVectors
Даны 2 вектора целых чисел одинаковой длины, заданные в сжатой форме списками пар вида (value, count).
Необходимо посчитать скалярное произведение заданных векторов.

### SummaryRanges
Дан список интов, повторяющихся элементов в списке нет.
Нужно преобразовать это множество в строку, сворачивая соседние по числовому ряду числа в диапазоны.

### SumSeries
Есть два ступенчатых графика некоторых наблюдаемых величин,
заданных отсортированными списками координат начала ступенек (<время измерения>, <значение>).
Подразумевается, что величина сохраняет своё значение между измерениями. До первого измерения величина равна нулю.
Требуется построить новый график, который будет являться суммой двух представленных

### ValidPalindrome
На входе дана непустая строка. Требуется выяснить, можно ли удалить из нее ровно один символ так, чтобы получился палиндром.

### VectorRemoveZeros
Удалить нули из вектора
Дан вектор, надо удалить из него нули, сохранив порядок остальных элементов.

### Anagrams
Проверить, являются ли две строки анаграммами
Даны две строки, нужно определить, являются ли они анаграммами (содержат ли одинаковые буквы в одинаковом количестве, но в разном порядке).

### BraceGrammar
Разворачивание скобочной грамматики
Дана строка со скобочным выражением, где в круглых скобках записано выражение, за которым следуют квадратные скобки с неотрицательным целым числом. Необходимо развернуть выражение в строку, повторив содержимое в скобках указанное количество раз.

### BracketSequenceGenerate
Генерация правильных скобочных последовательностей
Дано число n, необходимо сгенерировать все правильные скобочные последовательности из n пар скобок.

### CommonArrElementFinder
Поиск общего элемента в трех отсортированных массивах
Даны три неубывающих массива чисел. Найти число, которое присутствует во всех трех массивах. Решение должно работать за O(p + q + r), где p, q, r – длины массивов, с доп. памятью O(1).

### DeleteDuplicate
Удаление дубликатов из отсортированного массива
Дан отсортированный массив, необходимо удалить из него дубликаты на месте, чтобы каждый уникальный элемент присутствовал только один раз, сохранив их относительный порядок.

### DeleteSmiles
Удаление смайликов из текста
Дана строка с сообщением из соцсети, необходимо удалить из нее смайлики вида ":-)+" и ":-(" за линейное время, сохраняя остальной текст.

### DistanceBetweenTwoArrays
Поиск расстояния между двумя массивами
Даны два целочисленных массива и число d, необходимо найти количество элементов в первом массиве, для которых не существует элементов во втором массиве, расстояние до которых меньше или равно d.

### DuplicateArrElementFinder
Поиск повторяющегося элемента в массиве
Дан массив длины (n+1), содержащий натуральные числа от 1 до n. Найти любой повторяющийся элемент за время O(n), не изменяя массив и не используя дополнительной памяти.

### FindSortingSubarray
Поиск подмассива для сортировки
Даны две последовательности a и a', необходимо найти такой отрезок [l, r], что отсортировав подмассив a[l:r+1], можно получить массив a'. Если ответов несколько, выбрать отрезок наибольшей длины.

### GenerateParenthesis
Генерация комбинаций скобок
Дано число n, необходимо сгенерировать все возможные комбинации из n пар правильно вложенных скобок.

### Matrix
Генерация матрицы с шахматным узором
Дано целое неотрицательное число n, необходимо сгенерировать матрицу размера (2n + 1) × (2n + 1), где клетки раскрашены в шахматном порядке, на главной диагонали стоят нули, а в остальные клетки записываются числа по определенным правилам.

### MatrixLocalMinimum
Поиск локального минимума в матрице
Дана матрица nxn, содержащая попарно различные натуральные числа. Требуется найти в ней локальный минимум за время O(n).

### MergeIntervals
Объединение пересекающихся интервалов
Дан массив интервалов, необходимо объединить все пересекающиеся интервалы в непересекающиеся, которые покрывают все интервалы из входных данных.

### MinimumWindowSubstring
Поиск минимального окна подстроки
Даны две строки s и t, где t это непустой алфавит из уникальных символов. Необходимо найти наикратчайшую подстроку в s, которая содержит все символы из алфавита t.

### MovingAverage
Вычисление скользящего среднего
Дан поток целых чисел и размер окна, необходимо вычислить скользящее среднее для всех целых чисел в скользящем окне.

### NumberRangeCompression
Сжатие числовых диапазонов
Дан массив целых чисел без повторяющихся элементов. Нужно преобразовать его в строку, сворачивая соседние по числовому ряду числа в диапазоны.

### OxfordComma
Добавление Оксфордской запятой
Дана строка с перечислением элементов, необходимо добавить Оксфордскую запятую перед союзом в перечислениях из трех и более элементов.

### PlusOne
Увеличение числа на единицу
Дано большое целое число, представленное в виде массива цифр, необходимо увеличить это число на единицу и вернуть результирующий массив цифр.

### PointTraversalChecker
Проверка возможности обхода точек
Даны n точек с целочисленными координатами. Определить, можно ли посетить все точки, используя не более 3 различных типов перемещений из 4 возможных (U, R, D, L).

### SingleNumber
Поиск уникального числа
Дан непустой массив целых чисел, в котором каждый элемент встречается дважды, кроме одного. Найти это единственное число.

### StringCompression
Сжатие строки
Дан массив символов, необходимо сжать его, используя алгоритм, который заменяет группы последовательных повторяющихся символов на символ и количество повторений.

### SumOfSubarrayMins
Сумма минимумов подмассивов
Дан массив целых чисел, необходимо посчитать сумму минимумов каждого подмассива исходного массива.

### TextJustification
Выравнивание текста по ширине
Дан массив строк (слов) и максимальная ширина строки. Необходимо отформатировать текст так, чтобы каждая строка содержала ровно maxWidth символов и была полностью выровнена по ширине.

### TwoSum
Поиск двух чисел с заданной суммой
Дан массив целых чисел и целевое число, необходимо найти индексы двух чисел, сумма которых равна целевому значению.

### UrlCode
Кодирование URL
Заменить в массиве символы пробела на последовательность символов '%', '2', '0' по месту, гарантируя, что размер массива достаточен для этого.

### ValidMountainArray
Проверка валидности горного массива
Дан массив целых чисел, необходимо определить, является ли он валидным горным массивом (строго возрастает до пика и затем строго убывает).

### ValidParentheses
Проверка валидности скобок
Дана строка, содержащая только символы '(', ')', '{', '}', '[' и ']', определить, является ли входная строка валидной (скобки правильно закрыты и вложены).

### WordPatternMather
Сопоставление слов с шаблоном
Дан шаблон и строка, необходимо определить, соответствует ли строка шаблону, т.е. существует ли биекция между буквами в шаблоне и непустыми словами в строке.
